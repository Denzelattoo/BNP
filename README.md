
# ПО «Скрининг повышения НУП по ИИ-ЭКГ»

**Версия:** 1.0.0  
**Разработчик:** Институт персонализированной кардиологии, Сеченовский Университет

## Назначение
Расчёт вероятности повышения уровня натрийуретического пептида (NT-proBNP) в крови выше возрастной нормы
(более 125 пг/мл до 50 лет, более 150 пг/мл в 50–75 лет, более 450 пг/мл старше 75 лет)
по 47 параметрам одноканальной ЭКГ покоя длительностью 60 секунд, записанной в положении сидя.
Подключается к ПО/МИС в качестве backend-модуля. Результат носит вспомогательный характер
и не заменяет лабораторное определение NT-proBNP и решение врача.

## Состав
| Файл | Назначение |
|---|---|
| `loader_mod.py` | программа расчёта |
| `model_bnp.json` | Система выявления повышения НУП (обученная модель XGBoost) |
| `X_test.xlsx` | тестовый набор из 20 записей ЭКГ для проверки работоспособности |
| `requirements.txt` | список необходимых модулей Python |
| `README.md` | настоящий информационный файл |

## Требования
- Python не ниже 3.10;
- модули Python из `requirements.txt` (в том числе numpy, pandas, openpyxl, scipy, scikit-learn, xgboost не ниже 3.2.0);
- ОЗУ не менее 8 ГБ, свободное место на диске не менее 2 ГБ.

## Установка
```
pip install -r requirements.txt
```

## Запуск
```
python loader_mod.py
```
1. После сообщения «Введите полный путь к данным» укажите полный путь к файлу `.xlsx`
   (например, к `X_test.xlsx`).
2. После сообщения «Введите полный путь к Системе выявления повышения НУП по ИИ-ЭКГ»
   укажите полный путь к файлу `model_bnp.json`.
3. Результаты записываются в файл `bnp_test_results.txt` в папке с файлом данных.

## Входные данные
Файл `.xlsx`: одна строка — одна запись ЭКГ; столбцы — 47 параметров ЭКГ
(HFNoise, RR, TpTe, VAT, QTc, QT/TQ, HFQRS, HFSNR, JA, J80A, TA, QRSenergy, Tenergy, Tpenergy,
Sbeta, Beta, QRS11energy, QRS12energy, QRS2energy, QRSE1–QRSE4, TE1–TE4, QRSw, Pan, Pan.1, RA, SA,
Pst, Pfi, QRSst, QRSfi, Tfi, PpeakP, PpeakN, Rpeak, Speak, Tpeak, Tons, Toffs, RonsF, RoffsF, SDNN).
Необязательный столбец «ID записи» переносится в результаты.

## Выходные данные
Текстовый файл: для каждой записи — вероятность повышения NT-proBNP (число от 0 до 1)
и заключение по пороговому значению 0,55:
«Повышение НУП вероятно» (вероятность ≥ 0,55) или «Повышение НУП маловероятно».

## Сообщения об ошибках
| Сообщение | Причина | Действие |
|---|---|---|
| Ошибка при вводе пути! | неправильно указан путь к данным или к Системе | проверить правильность ввода пути |
| Ошибка формата файла! | файл не `.xlsx` (данные) или не `.json` (Система) | указать файл нужного формата |
| Ошибка входных данных | нет обязательных параметров ЭКГ, пустые или нечисловые значения | исправить файл данных |
